# Expense Tracker

A command-line expense tracker application built with Python and SQLite.

## Features

- Add expenses
- View all expenses
- View total spending
- Filter expenses by category
- Persistent SQLite database storage
- Input validation for expense amounts

## Technologies Used

- Python
- SQLite
- Git & GitHub

## How to Run

1. Clone the repository
2. Navigate to the project folder
3. Run the application

```bash
python main.py
```
